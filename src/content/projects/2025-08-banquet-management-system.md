A full-stack banquet management application built for planning, registration,
and reporting.

## What it does

- **Admin & User portals** for planning banquets, managing registrations, and generating reports
- Clean architecture across **Frontend → Server → Controller → DAO → Database**
- REST API surface with a **React** front end, backed by **Oracle DB** and built with **Gradle**

## Why it matters

The layered design kept separation of concerns clean and made the system
straightforward to extend — a good exercise in thinking about architecture
before writing code.
