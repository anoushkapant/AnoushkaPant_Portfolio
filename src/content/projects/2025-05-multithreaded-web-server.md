A high-performance web server built in **Python** using socket programming —
the classic exercise in understanding how the web actually works.

## What it does

- Handles **concurrent HTTP requests** efficiently
- Custom logging system for request tracking
- Optimized threading / asyncio architecture to stay responsive and scalable under load

## Why I built it

There's no better way to appreciate HTTP than writing the server yourself —
this project made TCP sockets, request parsing, and concurrency concrete.
